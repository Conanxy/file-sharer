# File Sharer v0.0.3

## English

This patch release fixes the macOS main window lifecycle after closing the window with the red close button.

### What's fixed

- Fixed macOS Dock reopen behavior.
  After closing the main window, clicking the File Sharer Dock icon now shows and focuses the main window again.
- Changed the macOS close action for the main window to hide the window instead of destroying it.
  This keeps the app running in the expected macOS style and makes reopening reliable.

### Notes

- Built from the latest committed code after v0.0.2.
- Release assets are generated by GitHub Actions.

## 中文

这个补丁版本修复了 macOS 上点击红色关闭按钮后，主窗口无法通过 Dock 图标重新打开的问题。

### 修复内容

- 修复 macOS Dock 重新打开行为。
  主窗口被关闭后，再点击 File Sharer 的 Dock 图标，现在会重新显示并聚焦主窗口。
- 调整 macOS 主窗口关闭逻辑。
  点击红色关闭按钮时隐藏主窗口，而不是销毁窗口，使应用更符合 macOS 的常见运行方式。

### 说明

- 本版本基于 v0.0.2 之后的最新提交构建。
- 安装包由 GitHub Actions 自动生成。
