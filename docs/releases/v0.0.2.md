# File Sharer v0.0.2

## English

This release focuses on LAN discovery reliability, the desktop drag-to-send flow, and icon polish across macOS and Android.

### What's new

- Improved LAN discovery behavior between macOS and Android.
  Devices now react much faster to discovery enable/disable changes, and refresh/probe behavior is more reliable.
- Added a desktop-only setting: `Send immediately after drop`.
  When enabled, dropped files are sent directly.
  When disabled, dropped files stay in a confirmation panel so you can switch target devices, add more files, cancel, or send manually.
- Refined the desktop overlay interaction.
  The refresh button animation was improved, the confirmation panel behavior was stabilized, and the overlay layout/scrolling/expanded state were polished for multi-file sending.
- Updated app icons and launcher assets.
  macOS and Android icons were regenerated and adjusted to provide better padding and visual balance.
- Improved Android file opening behavior.
  Opening received files now uses the direct system viewer flow instead of forcing an extra chooser step.

### Notes

- Manually tested on:
  - Android arm64
  - macOS Apple Silicon M4
- Windows, macOS Intel, and other environments are automatically built but not manually tested in this release.

## 中文

这个版本主要集中在三部分：局域网发现稳定性、桌面端拖放发送流程，以及 macOS / Android 图标细节优化。

### 更新内容

- 改进了 macOS 和 Android 之间的局域网发现体验。
  设备对“开启 / 关闭局域网发现”的响应更快，刷新 / 主动探测也更稳定。
- 新增桌面端专属设置：`拖放后立即发送`。
  开启时，拖入文件后会直接发送。
  关闭时，文件会先停留在确认面板里，用户可以切换目标设备、继续添加文件、取消发送，或者手动点击发送。
- 优化了桌面端悬浮窗交互。
  刷新按钮动效更自然，确认发送面板的展开、滚动、底部操作区和多文件发送流程更稳定。
- 更新了应用图标与启动图标资源。
  重新生成并调整了 macOS 与 Android 的图标资源，让留白和视觉比例更合理。
- 优化了 Android 打开文件的行为。
  接收后的文件现在更倾向于直接交给系统查看器打开，不再强制多一步 chooser 选择。

### 说明

- 已手动测试的平台：
  - Android arm64
  - macOS Apple Silicon M4
- Windows、macOS Intel 和其他环境会自动构建，但本次版本没有做人工完整验证。
